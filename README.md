# Allen Library Management System

## Overview
This repository contains the codebase for a library management system. The system is designed to help librarians and users manage book loans, returns, and inventory effectively.

## Features
- Book catalog management
- User account management
- Loan and return tracking
- Search functionality
- Overdue notifications
